ScaryTales Publisher

Private single-user tool: a Colab notebook that schedules and publishes finished horror-short videos to the owner's own Facebook Page.

Privacy

This tool does not collect, store, or sell any user data. It uses a Facebook Page access token, cached only inside the owner's private Colab runtime, to post videos to the owner's own Page. No data is shared with third parties.

Data deletion

No personal data is stored by this tool, so there is nothing to delete. To revoke access, remove the app from your Facebook settings; to request this form's removal, contact the app owner.
